# 系统模块拆分：Windows DoIP ECU 模拟器

本文基于 `Product-Brief.md`，将产品拆分为可实施、可验收、可演进的系统模块。当前边界：Windows 本地运行、命令行启动、Web 控制台访问、单 DoIP Entity、单逻辑地址。

## 模块总览

| 模块 | 复杂度 | 风险 | 说明 |
| --- | --- | --- | --- |
| 启动与运行时模块 | 中 | 中 | 负责进程启动、配置加载、服务编排、URL 输出 |
| Web 控制台模块 | 高 | 中 | 负责实时观测、配置编辑、异常注入操作入口 |
| 控制面 API 模块 | 中 | 中 | 负责 Web 控制台与仿真内核之间的命令和状态同步 |
| 配置与持久化模块 | 中 | 中 | 负责 JSON/YAML 配置读写、运行时配置版本管理 |
| ODX/PDX 导入模块 | 高 | 高 | 负责从 ODX/PDX 提取 ECU、DID、DTC、Routine 等配置 |
| DoIP 网络传输模块 | 高 | 高 | 负责 UDP/TCP/TLS socket、连接生命周期和网络收发 |
| DoIP 协议模块 | 高 | 高 | 负责 ISO 13400 消息解析、校验、响应和路由激活 |
| TLS 与证书模块 | 高 | 高 | 负责 DoIP over TLS、双向认证、证书错误模拟 |
| UDS 协议服务模块 | 高 | 高 | 负责 ISO 14229 服务分发、服务处理和响应编码 |
| ECU 状态机模块 | 高 | 高 | 负责会话、安全、TesterPresent、刷写流程和前置条件 |
| 安全算法插件模块 | 高 | 高 | 负责 DLL 插件加载、调用、隔离和 ABI 管理 |
| 异常注入模块 | 高 | 高 | 负责网络层、DoIP 层、UDS 层异常行为模拟 |
| 日志与事件模块 | 高 | 中 | 负责结构化事件、实时日志、文件日志和状态变化记录 |
| PCAP 录制模块 | 中 | 高 | 负责生成 Wireshark 可识别的 pcap 文件 |
| 性能与资源治理模块 | 中 | 中 | 负责吞吐、限流、缓冲、文件大小和长稳运行 |

## 1. 启动与运行时模块

### 负责什么

- 提供 Windows 命令行启动入口。
- 初始化运行目录、默认配置、日志目录、pcap 输出目录。
- 加载配置文件和证书配置。
- 启动 Web 控制台、控制面 API、DoIP UDP/TCP/TLS 服务。
- 在控制台输出本地 Web URL。
- 管理服务生命周期：启动、停止、优雅退出、异常恢复。

### 不负责什么

- 不直接处理 DoIP/UDS 协议细节。
- 不直接渲染 Web UI。
- 不直接解析 ODX/PDX。
- 不实现诊断状态机。

### 输入输出

- 输入：命令行参数、默认配置文件、环境变量、运行目录。
- 输出：本地 Web URL、进程状态、启动日志、模块初始化结果。

### 依赖哪些模块

- 配置与持久化模块
- Web 控制台模块
- 控制面 API 模块
- DoIP 网络传输模块
- TLS 与证书模块
- 日志与事件模块

### 复杂度和风险等级

- 复杂度：中
- 风险：中
- 主要风险：启动顺序、端口占用、证书路径错误、服务异常退出后的资源释放不完整。

## 2. Web 控制台模块

### 负责什么

- 提供 Vue 前端界面。
- 展示实时连接状态、DoIP 报文、UDS 报文、状态机状态、日志流、pcap 录制状态。
- 支持运行中修改 DID、注入 DTC、改变会话状态、安全解锁状态。
- 支持切换异常策略、暂停/恢复响应、手动发送 NRC、自定义响应。
- 提供基础配置管理界面：VIN、EID、GID、端口、逻辑地址、白名单、证书路径、DID/DTC/Routine 配置。
- 提供 ODX/PDX 导入入口。

### 不负责什么

- 不直接打开 socket。
- 不直接处理 DoIP/UDS 协议。
- 不直接写 pcap 文件。
- 不承诺多用户权限、远程协作、企业级审计。

### 输入输出

- 输入：控制面 API 返回的状态、日志、配置、事件流。
- 输出：用户操作命令、配置变更、异常注入请求、导入文件。

### 依赖哪些模块

- 控制面 API 模块
- 配置与持久化模块
- 日志与事件模块
- 异常注入模块
- ODX/PDX 导入模块

### 复杂度和风险等级

- 复杂度：高
- 风险：中
- 主要风险：高频日志导致 UI 卡顿；运行中配置变更需要清晰反馈；调试操作过多时界面容易失控。

## 3. 控制面 API 模块

### 负责什么

- 连接 Web 控制台与仿真内核。
- 提供内部 HTTP/WebSocket 通道，用于配置读取、配置更新、状态订阅、日志订阅和控制命令下发。
- 将用户操作转换为仿真内核可执行的命令。
- 对运行中变更做权限边界和参数校验。
- 返回命令执行结果和错误信息。

### 不负责什么

- 不作为对外公开 SDK。
- 不承诺稳定公共 API 兼容性。
- 不提供 CI 无界面自动化接口。
- 不直接实现 UDS 服务逻辑。

### 输入输出

- 输入：Web 控制台请求、事件订阅请求、配置变更请求。
- 输出：配置数据、实时状态、日志事件、命令执行结果、错误响应。

### 依赖哪些模块

- 配置与持久化模块
- ECU 状态机模块
- 异常注入模块
- 日志与事件模块
- PCAP 录制模块
- DoIP 协议模块
- UDS 协议服务模块

### 复杂度和风险等级

- 复杂度：中
- 风险：中
- 主要风险：控制命令与协议处理并发冲突；运行中修改配置可能导致状态不一致。

## 4. 配置与持久化模块

### 负责什么

- 管理 JSON/YAML 配置读写。
- 维护当前 ECU 配置：VIN、EID、GID、逻辑地址、端口、白名单、DID、DTC、Routine、Session、SecurityAccess、Flash 流程、证书路径。
- 支持配置校验、默认值填充、配置版本迁移。
- 保存 Web 控制台修改后的配置。
- 管理运行时配置快照，支持异常场景复现。

### 不负责什么

- 不负责 ODX/PDX 语义解析。
- 不直接执行配置变更产生的协议行为。
- 不负责日志文件和 pcap 文件的写入。

### 输入输出

- 输入：本地配置文件、Web 控制台配置变更、ODX/PDX 导入结果。
- 输出：标准化 ECU 配置对象、配置校验结果、持久化文件。

### 依赖哪些模块

- ODX/PDX 导入模块
- 日志与事件模块

### 复杂度和风险等级

- 复杂度：中
- 风险：中
- 主要风险：运行时配置与持久化配置不一致；配置结构后续扩展时兼容性不足。

## 5. ODX/PDX 导入模块

### 负责什么

- 导入 `.odx` 文件和 `.pdx` 压缩包。
- 解析第一阶段需要的 ECU 基本信息、DID、DTC、Routine、SecurityAccess、Session、Flash 下载相关配置。
- 将 ODX/PDX 内容转换为内部标准配置模型。
- 输出导入报告：成功项、跳过项、不支持项、错误项。

### 不负责什么

- 不承诺通用 ODX 全量解析。
- 不负责执行诊断服务。
- 不负责修复不规范或缺失严重的 ODX 数据。
- 不负责第三方工具链专项认证。

### 输入输出

- 输入：`.odx` 文件、`.pdx` 文件、导入选项。
- 输出：标准化 ECU 配置片段、导入报告、错误列表。

### 依赖哪些模块

- 配置与持久化模块
- 日志与事件模块

### 复杂度和风险等级

- 复杂度：高
- 风险：高
- 主要风险：ODX 数据结构复杂；不同来源 ODX 差异大；Flash、SecurityAccess、DTC 的语义映射容易不完整。

## 6. DoIP 网络传输模块

### 负责什么

- 管理 UDP、TCP、TLS 网络监听与收发。
- 支持车辆公告 UDP、车辆识别请求接收、TCP/TLS 连接建立。
- 管理 20 个并发 TCP/TLS 连接目标。
- 管理连接生命周期：连接、断开、超时、Alive Check 触发。
- 向上层提交原始 DoIP 数据帧。
- 接收上层编码后的 DoIP 响应并发送。

### 不负责什么

- 不解释 UDS 服务语义。
- 不决定路由激活是否成功。
- 不直接生成业务 NRC。
- 不负责 Web UI 展示。

### 输入输出

- 输入：网卡/IP/端口配置、证书上下文、客户端连接、网络字节流。
- 输出：连接事件、原始 DoIP 帧、发送结果、网络错误事件。

### 依赖哪些模块

- TLS 与证书模块
- DoIP 协议模块
- 异常注入模块
- 日志与事件模块
- PCAP 录制模块

### 复杂度和风险等级

- 复杂度：高
- 风险：高
- 主要风险：TCP 粘包/半包处理；TLS 与普通 TCP 双栈共存；异常注入不能破坏正常连接稳定性。

## 7. DoIP 协议模块

### 负责什么

- 实现 ISO 13400 DoIP 报文解析、校验和编码。
- 处理协议版本、inverse version、payload type、payload length。
- 实现车辆识别响应、实体状态响应、诊断电源模式响应、路由激活、Alive Check、诊断消息封装。
- 校验逻辑地址和源地址白名单。
- 将 UDS payload 转发给 UDS 协议服务模块。

### 不负责什么

- 不实现 UDS 服务具体业务。
- 不直接执行 TLS 握手。
- 不直接写 pcap。
- 不负责配置文件格式。

### 输入输出

- 输入：DoIP 原始帧、连接上下文、Entity 配置、异常策略。
- 输出：DoIP 响应帧、UDS 请求、协议错误事件、路由激活状态。

### 依赖哪些模块

- DoIP 网络传输模块
- UDS 协议服务模块
- ECU 状态机模块
- 异常注入模块
- 配置与持久化模块
- 日志与事件模块

### 复杂度和风险等级

- 复杂度：高
- 风险：高
- 主要风险：协议边界条件多；路由激活和连接状态容易出现不一致；错误 header 模拟需要与正常校验机制解耦。

## 8. TLS 与证书模块

### 负责什么

- 支持 DoIP over TLS 真实握手。
- 支持服务端证书配置、客户端证书校验、双向认证。
- 支持证书错误模拟：过期、不匹配、不受信任、客户端证书缺失等。
- 为 TLS 连接提供握手结果、证书链信息和错误原因。
- 为 pcap 可分析性提供必要的辅助能力，例如可选 TLS key log 输出。

### 不负责什么

- 不负责 UDS `0x84` 数据内容加解密策略。
- 不负责 SecurityAccess 种子密钥算法。
- 不负责证书签发系统。
- 不保证 Wireshark 自动解密 TLS 内容，除非配套 key log 或解密配置。

### 输入输出

- 输入：证书文件、私钥文件、CA 配置、TLS 策略、客户端握手请求。
- 输出：TLS 连接上下文、握手事件、证书校验结果、TLS 错误事件。

### 依赖哪些模块

- DoIP 网络传输模块
- 配置与持久化模块
- 异常注入模块
- 日志与事件模块
- PCAP 录制模块

### 复杂度和风险等级

- 复杂度：高
- 风险：高
- 主要风险：双向认证配置复杂；证书错误模拟要可控；TLS 报文 pcap 能识别但不一定能解密。

## 9. UDS 协议服务模块

### 负责什么

- 实现 ISO 14229 UDS 服务分发与响应编码。
- 覆盖 `0x10/0x11/0x14/0x19/0x22/0x27/0x28/0x2E/0x2F/0x31/0x34-0x37/0x3E/0x85/0x84`。
- 根据 ECU 配置处理 DID、DTC、Routine、SecurityAccess、Session 和 Flash 下载流程。
- 生成正响应、负响应 NRC、`0x78 ResponsePending`。
- 处理 P2/P2* 定时相关响应策略。

### 不负责什么

- 不直接处理 socket。
- 不直接执行 DoIP 路由激活。
- 不负责 Web 控制台展示。
- 不直接加载 DLL 插件，只通过安全算法插件模块调用。

### 输入输出

- 输入：UDS 请求、会话上下文、安全状态、ECU 配置、异常策略。
- 输出：UDS 响应、NRC、服务执行事件、状态机变更请求。

### 依赖哪些模块

- ECU 状态机模块
- 配置与持久化模块
- 安全算法插件模块
- 异常注入模块
- 日志与事件模块

### 复杂度和风险等级

- 复杂度：高
- 风险：高
- 主要风险：服务覆盖面大；服务间前置条件复杂；刷写流程和安全访问容易出现状态漏洞。

## 10. ECU 状态机模块

### 负责什么

- 维护单逻辑地址 ECU 的运行状态。
- 管理诊断会话状态、SecurityAccess 解锁状态、TesterPresent 超时、通信控制状态、DTC 设置状态。
- 管理刷写流程状态：下载请求、传输块序号、传输中、退出传输、失败恢复。
- 提供服务前置条件判断。
- 提供运行中状态修改接口，供 Web 控制台调试使用。

### 不负责什么

- 不负责网络收发。
- 不直接解析 UDS 字节流。
- 不负责持久化配置文件。
- 不负责 DLL 插件加载。

### 输入输出

- 输入：UDS 服务事件、Web 控制台状态修改命令、定时器事件、配置数据。
- 输出：当前 ECU 状态、前置条件判断结果、状态变化事件、超时事件。

### 依赖哪些模块

- 配置与持久化模块
- UDS 协议服务模块
- 日志与事件模块

### 复杂度和风险等级

- 复杂度：高
- 风险：高
- 主要风险：状态组合多；并发请求和运行中人工修改可能造成状态竞争；P2/P2* 与 TesterPresent 定时需要精确。

## 11. 安全算法插件模块

### 负责什么

- 加载 OEM 安全算法 DLL 插件。
- 定义插件 ABI、版本号、初始化、释放、算法调用、错误码规范。
- 支持 SecurityAccess `0x27` 的 seed/key 计算。
- 支持 SecuredDataTransmission `0x84` 相关安全处理扩展。
- 提供调用超时、错误捕获、插件状态上报。

### 不负责什么

- 不负责证书链校验。
- 不负责 TLS 握手。
- 不负责 UDS 服务分发。
- 不保证第三方 DLL 绝对安全。

### 输入输出

- 输入：DLL 路径、算法参数、seed/key 请求、`0x84` 安全处理请求。
- 输出：算法结果、错误码、插件加载状态、调用耗时事件。

### 依赖哪些模块

- 配置与持久化模块
- UDS 协议服务模块
- 日志与事件模块

### 复杂度和风险等级

- 复杂度：高
- 风险：高
- 主要风险：DLL 崩溃会影响主进程；ABI 兼容性难维护；插件阻塞会拖慢诊断响应。

## 12. 异常注入模块

### 负责什么

- 管理可复现的异常策略。
- 支持网络层异常：丢包、延迟、乱序、断开 TCP、半包、粘包。
- 支持 DoIP 层异常：错误 payload type、错误 inverse version、错误 length、路由激活失败。
- 支持 TLS 层异常：握手失败、证书过期、不匹配、不受信任。
- 支持 UDS 层异常：暂停响应、手动 NRC、自定义响应、ResponsePending 注入。
- 支持运行时切换异常策略。

### 不负责什么

- 不负责定义 UDS 正常业务逻辑。
- 不负责保存配置文件，除非通过配置模块持久化策略。
- 不负责 UI 操作入口。

### 输入输出

- 输入：异常策略配置、Web 控制台控制命令、协议上下文、连接上下文。
- 输出：修改后的发送行为、异常事件、注入结果、可复现策略记录。

### 依赖哪些模块

- DoIP 网络传输模块
- DoIP 协议模块
- TLS 与证书模块
- UDS 协议服务模块
- ECU 状态机模块
- 日志与事件模块

### 复杂度和风险等级

- 复杂度：高
- 风险：高
- 主要风险：异常注入跨层；需要保证异常可复现；错误注入不能污染正常路径状态。

## 13. 日志与事件模块

### 负责什么

- 统一收集结构化事件。
- 覆盖 DoIP 帧级、UDS 服务级、TCP/TLS 连接事件、状态机变化、配置变更、异常注入事件。
- 支持实时日志推送到 Web 控制台。
- 支持文件日志异步写入。
- 支持日志等级、分类、过滤、采样和环形缓冲。
- 为问题复现提供时间线。

### 不负责什么

- 不负责 pcap 二进制文件格式。
- 不负责 UI 渲染。
- 不负责决定协议响应。
- 不负责长期集中式日志平台，例如 ELK/Grafana。

### 输入输出

- 输入：各模块事件、报文摘要、状态变化、错误信息。
- 输出：实时日志流、文件日志、事件查询结果、运行时间线。

### 依赖哪些模块

- 配置与持久化模块
- 控制面 API 模块

### 复杂度和风险等级

- 复杂度：高
- 风险：中
- 主要风险：100M 日志吞吐下可能造成 IO 压力；实时 UI 消费速度低于生产速度时需要丢弃或采样策略。

## 14. PCAP 录制模块

### 负责什么

- 将网络通信记录为 Wireshark 可打开的 pcap 文件。
- 控制 pcap 文件大小上限 500M。
- 记录 DoIP/TCP/TLS 相关数据包，支持 Wireshark 识别。
- 管理录制启动、停止、轮转、文件命名和错误处理。
- 可选输出 TLS key log 或解密辅助信息，用于诊断内容分析。

### 不负责什么

- 不负责 Wireshark 软件本身配置。
- 不保证 TLS 内容天然可解密。
- 不负责结构化业务日志。
- 不负责替代实时 Web 日志。

### 输入输出

- 输入：网络收发数据、连接元数据、录制配置、TLS 辅助信息。
- 输出：`.pcap` 文件、录制状态、文件轮转事件、错误事件。

### 依赖哪些模块

- DoIP 网络传输模块
- TLS 与证书模块
- 配置与持久化模块
- 日志与事件模块

### 复杂度和风险等级

- 复杂度：中
- 风险：高
- 主要风险：用户期望“识别”和“解密”容易混淆；pcap 写入性能和文件大小控制需要严谨处理。

## 15. 性能与资源治理模块

### 负责什么

- 管理并发连接、请求吞吐、缓冲区、异步队列、文件 IO。
- 支持目标性能：20 并发 TCP/TLS 连接、200 请求/秒、稳定运行 1 天、日志吞吐量 100M、pcap 上限 500M。
- 提供背压策略、限流策略、队列溢出策略。
- 提供运行指标：连接数、RPS、队列长度、日志写入速率、pcap 写入速率、内存占用、错误计数。

### 不负责什么

- 不直接实现协议业务。
- 不负责 Web 页面布局。
- 不负责生成测试报告。
- 不负责企业级监控系统对接。

### 输入输出

- 输入：各模块运行指标、队列状态、资源使用情况、性能配置。
- 输出：性能指标、限流决策、告警事件、资源治理动作。

### 依赖哪些模块

- DoIP 网络传输模块
- 日志与事件模块
- PCAP 录制模块
- 控制面 API 模块

### 复杂度和风险等级

- 复杂度：中
- 风险：中
- 主要风险：日志、pcap、实时 UI 同时开启时资源竞争明显；长稳运行需要防止内存和句柄泄漏。

## 推荐模块依赖方向

建议保持以下依赖方向，避免协议层、控制层、UI 层互相耦合：

```text
Web 控制台
  -> 控制面 API
    -> 配置与持久化
    -> ECU 状态机
    -> 异常注入
    -> 日志与事件
    -> PCAP 录制

DoIP 网络传输
  -> TLS 与证书
  -> DoIP 协议
    -> UDS 协议服务
      -> ECU 状态机
      -> 安全算法插件
      -> 配置与持久化

所有核心模块
  -> 日志与事件
  -> 性能与资源治理
```

## 第一阶段建议优先级

| 优先级 | 模块 | 原因 |
| --- | --- | --- |
| P0 | 启动与运行时模块 | 没有统一启动入口，无法形成可用产品形态 |
| P0 | 配置与持久化模块 | 所有协议和 UI 都依赖稳定配置模型 |
| P0 | DoIP 网络传输模块 | 真实诊断上位机连接的基础 |
| P0 | DoIP 协议模块 | 发现、路由激活和诊断消息封装的基础 |
| P0 | UDS 协议服务模块 | 产品核心价值 |
| P0 | ECU 状态机模块 | 决定模拟真实性 |
| P1 | Web 控制台模块 | 实时调试的主要入口 |
| P1 | 控制面 API 模块 | 支撑 Web 控制台与内核解耦 |
| P1 | 日志与事件模块 | 调试和验收必需 |
| P1 | TLS 与证书模块 | 安全诊断核心能力 |
| P1 | PCAP 录制模块 | 问题定位和验收必需 |
| P2 | 安全算法插件模块 | OEM 扩展能力，需要先冻结 ABI |
| P2 | 异常注入模块 | 建议分层逐步实现 |
| P2 | ODX/PDX 导入模块 | 复杂度高，建议先支持配置文件闭环 |
| P2 | 性能与资源治理模块 | 需要伴随压测逐步加强 |
